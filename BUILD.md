# Building and releasing

A Trusted Web Activity wrapper around `https://truce.net`, generated by bubblewrap.
There is no app code beyond the TWA launcher — the site is the app.

## Toolchain

- JDK 17 (`/usr/libexec/java_home -v 17`)
- Android SDK at `~/Library/Android/sdk`, with `platforms;android-36`, `build-tools;36.0.0`,
  `platform-tools`, installed via `cmdline-tools/latest/bin/sdkmanager`
- Gradle wrapper and AGP versions are pinned in `gradle/wrapper/gradle-wrapper.properties`
  and `build.gradle`

If the SDK is missing, install the command line tools from
`https://dl.google.com/android/repository/commandlinetools-mac-<build>_latest.zip`, unzip to
`~/Library/Android/sdk/cmdline-tools/latest`, then `yes | sdkmanager --licenses` and install
the packages above.

## Signing

The upload key lives at `~/Desktop/archive/android.keystore`, alias `android`, backed up to
`~/Library/Mobile Documents/com~apple~CloudDocs/Backups/truce-android-keystore/` alongside a
README holding the password. Google Play will reject any bundle signed with a different key.

The Gradle build produces an unsigned bundle; sign it separately:

    jarsigner -sigalg SHA256withRSA -digestalg SHA-256 \
      -keystore ~/Desktop/archive/android.keystore \
      -signedjar app-release-bundle.aab \
      app/build/outputs/bundle/release/app-release.aab android

Verify with `jarsigner -verify -certs app-release-bundle.aab`. The certificate SHA-256 is
`FF:C6:49:32:C4:15:00:3A:1D:3F:54:5E:19:CE:32:EF:BD:01:3D:68:BE:FF:07:51:C4:6E:C8:6C:70:8C:A0:86`.

## Releasing

Google Play requires each update to target a recent API level, and emails a deadline when the
current release falls behind. To answer one:

1. Raise `compileSdkVersion` and `targetSdkVersion` in `app/build.gradle` to the required level,
   and install the matching SDK platform and build-tools. Bump AGP and the Gradle wrapper if the
   new `compileSdk` needs it.
2. Increment `versionCode` and `versionName` in `app/build.gradle`, and mirror them into
   `twa-manifest.json` as `appVersionCode`, `appVersionName`, and `appVersion`. The `versionCode`
   must exceed the one live on Play.
3. `ANDROID_HOME=~/Library/Android/sdk ./gradlew bundleRelease`, then sign as above.
4. Play Console → Test and release → Production → Create new release → upload the signed `.aab`
   → Next → Save → Publishing overview → Submit for review.

## Verifying before release

`bundletool build-apks --mode=universal` turns the bundle into an installable APK. Install it on
an emulator running the newly targeted API level and confirm the launcher starts the TWA and the
site renders:

    adb install -r universal.apk
    adb shell am start -n net.truce.twa/net.truce.twa.LauncherActivity

A fresh emulator spends its first several minutes updating Play services, and Chrome will ANR
under that load on a software renderer. Let it settle and relaunch before reading anything into it.
